# Mobile Business Lite

Bare-minimum, precise bookkeeping web app for a two-partner mobile-phone trading business.
It replaces the Excel workbooks.

- Specs: [`docs/PRD.md`](docs/PRD.md) · [`docs/SRS.md`](docs/SRS.md) · [`docs/UIDD.md`](docs/UIDD.md) · Tasks: [`docs/TASKS.md`](docs/TASKS.md) · Decisions: [`docs/DECISIONS.md`](docs/DECISIONS.md)
- Stack: Next.js 16 · Supabase (Postgres + Auth) · Drizzle · Tailwind/shadcn · Vitest + Playwright
- Status: specs ready; build progress is tracked in `docs/TASKS.md`.
